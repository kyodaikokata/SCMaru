# SCMaru · SC丸

**スパチャの整理をしましょうね♪**

SCMaru は、Bilibili（哔哩哔哩）ライブのスーパーチャット（SC／スパチャ）を整理する Windows アプリです。SC の送信時刻、ユーザー名、本文、金額を一覧にし、ギフトやメンバー加入（大航海）も配信ごとに集計します。

[Windows 版をダウンロード](https://github.com/kyodaikokata/SCMaru/releases/latest) · [简体中文](#简体中文)

## 使い方

1. Windows x64 用 ZIP をすべて展開し、`SCMaru/SCMaru.exe` を起動します。`_internal` フォルダーは EXE と同じ場所に置いてください。
2. メイン画面で Bilibili のルーム ID を入力して接続します。QR ログインは任意です。ゲスト接続ではギフト送信者の情報が一部伏せられる場合があります。
3. 配信に残り SC 件数を表示する場合は「URL をコピー」を押し、Bilibili 直播姫（LiveHime）のブラウザー素材に貼り付けます。データは Bilibili のルームから受信します。

## 主な機能

- 左クリックで緑の○（対応済み）、右クリックで黄色の△（確認待ち）、中クリックで青の□（その他）。本文をクリックすると原文の BV 番号をコピーできます。ユーザー名は漢字、ピンイン、頭文字で検索できます。
- 動画鑑賞モードでは BV 番号のない未マークの SC を青の□に分類し、まとめて対応済みにできます。
- SC、ギフト、大航海の支援額をユーザー別に集計します。配信が日付をまたいでも同じ枠として扱い、SC は配信開始日時ごとに TXT へ保存します。履歴からリセット前の記録を復元できます。
- SC の中国語・日本語を自動判定し、詳細で選択した SC を翻訳します。一覧には取得済みの訳文だけを表示できます。詳細の原文は訳文がある場合に非表示にできます。翻訳時は対象の本文が選択した翻訳サービスに送信されます。
- 透明なブラウザー素材に残り SC 件数や任意の文字を表示できます。文字のフォント、縁取り、影、発光を設定できます。水分補給・運動のリマインダーもあります。

設定と記録は `%LOCALAPPDATA%/SCMaru` に保存され、TXT はその中の `exports` に入ります。支援額はアプリが受信したイベントの集計値です。

## 简体中文

**SCMaru（SC丸）** 是一款 Windows 哔哩哔哩直播 SC（醒目留言）管理工具，可记录发送时间、昵称、正文和金额，并按场次汇总礼物、上舰和 SC 打赏。

[下载 Windows 版](https://github.com/kyodaikokata/SCMaru/releases/latest) · [版本记录](CHANGELOG.md)

### 快速开始

1. 完整解压 Windows x64 ZIP，运行 `SCMaru/SCMaru.exe`，保留旁边的 `_internal` 文件夹。
2. 在主界面输入 B 站直播间号并连接。扫码登录可跳过，游客接收的送礼用户信息可能被隐藏。
3. 如需在直播姬显示剩余 SC，点击「复制 URL」，将完整地址粘贴到浏览器或网页素材中。打赏数据由 SCMaru 连接 B 站直播间获取。

### 主要功能

- 在标记格左键打绿圈（已处理）、右键打黄三角（待确认）、中键打蓝方块（其它）。点击正文复制原文 BV 号，支持汉字、拼音和首字母搜索昵称。
- 视频鉴赏模式自动给不含 BV 号的未标记 SC 打蓝方块，可批量转为已处理。
- 按用户汇总 SC、礼物及上舰金额。跨午夜仍按同一场直播统计，SC 按开播日期和时间保存为 TXT，可从历史恢复重置前的记录。
- 自动识别中日文，在详情栏翻译选中的 SC。列表可显示详情栏已缓存的译文。详情仅在已有译文时隐藏原文。翻译时，相应 SC 正文会发送给所选翻译服务。
- 直播姬透明画面可显示剩余 SC 和自定义文字，支持字体、描边、阴影和发光。另有喝水和活动提醒。

配置和记录保存在 `%LOCALAPPDATA%/SCMaru`，TXT 位于其中的 `exports`。打赏榜金额为应用已采集的事件合计。

## ソースから実行 / 从源码运行

Windows · Python 3.12

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

`app.py --demo` でサンプルデータを表示できます。可用 `app.py --demo` 查看模拟数据。
